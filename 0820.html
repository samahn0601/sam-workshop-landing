4문헌 찾기 · 딥리서치를 한 화면에서

1. Ctrl + T — 인앱 브라우저가 열립니다.

Ctrl+Shift+B로도 열리지만 그건 열기/닫기 토글이라 한 번 더 누르면 닫힙니다. Ctrl+T가 안전합니다.

2. ⚠️ 그 안에서 ChatGPT에 로그인하세요 — 크롬에 로그인돼 있어도 여기선 따로입니다.

3. 딥리서치를 켜고 아래를 붙여넣으세요.

[내 연구질문]의 핵심 문헌을 찾아줘. 출처마다 저자·연도·저널·DOI(또는 PMID)·핵심 결과(가능하면 원문 1줄 인용)·한계를 정리하고, 최신 가이드라인·체계적 고찰·반박 근거도 포함해줘. 확인 가능한 인용만 — 출처 없는 일반론은 제외.

4. 결과가 나오면 Codex로 돌아와 "결과 가져와줘". 화면을 직접 읽어 파일로 저장합니다.

승인 창이 뜨면 "허용"을 누르세요. 한 번만 누르면 됩니다.
🔁 안 되면 그냥 복사해서 붙여넣으셔도 됩니다. 결과물은 똑같습니다 — 여기서 멈추지 마세요.
⚠️ 어느 방법으로 모으셨든 모든 인용은 ⑤ 인용 검증으로 실재 확인합니다. AI가 그럴듯하게 지어낸 참고문헌은 육안으로 구별되지 않습니다.

7더 넓히기 · 여유가 되는 만큼 · 안 하셔도 실습에 지장 없습니다

① Git — 원고를 되돌릴 수 있게 선택

원고를 고치다 보면 "아까 그 문장이 나았는데" 하는 순간이 옵니다. Git이 있으면 어느 시점으로든 되돌릴 수 있습니다.

ChatGPT는 Claude와 달리 Git을 처음부터 요구하지 않습니다. 없어도 오늘 실습은 전부 됩니다. 다만 원고 이력 관리에는 있는 편이 낫습니다.

아래를 그대로 붙여넣으면 설치까지 알아서 합니다 — 설치 파일 정리까지 포함입니다.

Git이 설치돼 있는지 확인하고, 없으면 설치해 줘. 순서는 이렇게: 1. 먼저 `git --version` 으로 확인해. 이미 있으면 버전만 알려주고 끝내. 2. 없으면 — Windows는 `winget install --id Git.Git -e --source winget` 을 먼저 시도해. 설치 파일이 남지 않아 가장 깔끔해. (Mac이면 `brew install git`) 3. winget이 없거나 실패하면: git-scm.com에서 최신 64비트 설치 파일을 임시 폴더에 받아 조용히 설치(/VERYSILENT /NORESTART)한 뒤, **받은 설치 파일을 반드시 삭제**해. 임시 폴더도 남기지 말고 정리해. 4. 새 셸에서 `git --version` 으로 재확인하고 결과를 한 줄로 알려줘. PATH에 안 잡히면 앱을 껐다 켜야 한다는 것도 알려줘. 각 단계에서 무엇을 할지 먼저 말하고 진행해. 실패하면 멈추고 무엇이 왜 실패했는지 알려줘. 관리자 권한이 필요하면 먼저 물어봐.

설치 후 원고 폴더에서 "지금 상태를 저장해 둬", 나중에 "아까 저장한 걸로 되돌려 줘" 라고 하시면 됩니다. Git 명령을 외우실 필요 없습니다.

⚠️ 아직 "제공되는 곳에서" 단계라 플랜·지역·기기·워크스페이스에 따라 안 보일 수 있습니다. 안 보여도 오늘 진행에 지장 없습니다.

🔒 인용 실재 확인날조 인용은 데스크 리젝트를 넘어 연구 진실성 문제가 됩니다.
🔒 제출은 사람이포털 로그인·제출 버튼은 저자 본인의 행위입니다. AI가 누르지 않습니다.
🔒 의학적 판단 확인약물 용량·IRB·가이드라인 서술은 저자가 책임집니다.
⚠️ 오늘 만드는 산출물은 투고를 향한 원고(submission-directed)이지 투고 가능한 원고(submission-ready)가 아닙니다. 실제 투고 전에 참고문헌·데이터·AI 공개문·공저자 승인을 본인이 최종 확인하셔야 합니다.
