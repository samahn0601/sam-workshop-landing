💊 오늘 만든 퀴즈·카드에 약물 용량(mg/kg) 같은 숫자가 보이면 — 그건 외우지 마세요. 오늘 소스는 용량 수치를 일부러 비워 둔 교육용 자료입니다. 그런데도 숫자가 나왔다면 AI가 배경지식으로 채운 것입니다. 출처 인용을 눌러 원문에 그 숫자가 없는 것을 직접 확인해 보세요 — 이게 오늘 배우는 검증 습관이고, 용량은 항상 최신 지침·제품정보로 확인합니다.

🚫 생성물 옆 ⋮는 누르지 마세요 — 메뉴에 「삭제」밖에 없습니다. 크게 보려면 펼치기(↗)를 쓰세요.

⚠️ 무료 한도: 오디오 ~3/일 · 동영상은 더 제한적 → 반에서 택1 규칙. 남은 횟수가 화면에 표시되지 않습니다(걸린 뒤에야 안내가 뜹니다). 학교 Workspace 계정이 막혀 있으면 개인 계정으로.

5트랙 실전 — 내 필요로 · Code로 돌아와 · 자유 이동

🅰 공부·시험 트랙

이 폴더의 notes_*.md 내용을 바탕으로 시험 대비 스터디가이드를 study_guide.md로 만들어줘. 주제별로 소제목을 나누고, 핵심 정의·표·암기 포인트를 정리해줘.
이 폴더의 notes_*.md 내용을 바탕으로 문제은행을 question_bank.md로 만들어줘. 객관식 15문항 + 단답형 5문항으로 구성하고, 문제마다 출제 근거가 된 노트 파일명을 표시해줘. 정답과 해설은 별도 섹션에 모아줘.
이 폴더의 notes_*.md 내용을 바탕으로 Anki에 바로 임포트할 수 있는 플래시카드를 anki_cards.csv로 만들어줘. 컬럼은 front,back 두 개만 쓰고, front는 질문/용어, back은 답/설명으로 채워줘. 헤더 행 포함해서 최소 15장 분량으로.

★ 완성 CSV는 Anki에서 파일 > 가져오기로 그대로 플래시카드 덱이 됩니다.

🅱 발표·과제 트랙

이 폴더의 자료들을 주제별로 묶어서 outline.md로 구조화해줘. 대주제-소주제-핵심 근거 3단 구조로 정리하고, 어느 파일에서 가져온 내용인지 출처도 같이 표시해줘.
방금 만든 outline.md를 바탕으로 발표 슬라이드 아웃라인을 slide_outline.md로 만들어줘. 슬라이드 장수는 10장 내외로, 슬라이드별로 제목 1줄 + 본문 불릿 3~4개 + (필요하면) 어떤 이미지가 들어가면 좋을지 한 줄 메모를 달아줘.
slide_outline.md의 각 슬라이드에 맞춰 발표 대본을 script.md로 만들어줘. 슬라이드 번호별로 실제 말하듯이 자연스러운 구어체로 작성하고, 슬라이드당 20~30초 분량으로 맞춰줘.

★ 케이스 발표(증례 보고) — PK·임상실습 대비

실습 폴더 안 case_presentation/에 가상 증례(폐렴)와 발표 골격이 들어 있습니다. 폴더를 바꿀 필요 없이 그대로 아래를 붙여넣으세요.

case_presentation 폴더의 case_virtual_01_pneumonia.md를 읽고, 같은 폴더의 case_template.md 발표 골격에 맞춰 증례 발표 개요를 case_presentation/case_outline.md로 만들어줘. 각 섹션을 채우되, 감별진단은 가능성 높은 순서로 3~5개 들고 각각 지지 소견/반대 소견을 표로 정리해줘.
방금 만든 case_presentation/case_outline.md를 바탕으로 7~8장짜리 증례 발표 슬라이드 아웃라인을 case_presentation/case_slides.md로 만들어줘. 마지막에 교수님이 물어볼 만한 예상 질문 5개와 모범 답변도 달아줘.

⚠️ 실제 환자 증례는 절대 입력 금지. 병원 실습에서 이 패턴을 쓰려면 반드시 가상화·완전 비식별 재작성본으로만 — 이 템플릿으로 연습하는 것 자체가 올바른 사용 습관.

🅐 ChatGPT 유료 구독이 이미 있다면 · 추가 비용 0

이미 내고 있는 구독을 Code 탭 안으로 끌어옵니다. Claude가 GPT를 직접 불러서 두 답을 나란히 보여줘요. 구독이 없으면 이걸 위해 새로 결제하지 마세요 — 오늘 배운 것만으로 충분합니다.

ChatGPT 유료 구독(Plus/Pro)이 있어서, 내 구독으로 GPT를 추가 과금 없이 연결하고 싶어. OpenAI 공식 Codex CLI를 쓰는 방식이야. 아래 순서대로 해주고, 시스템을 바꾸는 명령은 실행 전에 꼭 확인받아. 1) node와 npm이 있는지 확인하고, 없으면 관리자 권한 없이(user 설치) 깔아줘. 2) npm i -g @openai/codex 로 설치해줘. 3) codex login 을 실행해줘 — 브라우저가 열리면 내 ChatGPT 계정으로 로그인할게. 4) 어느 방식으로 붙었는지 확인해줘: 홈 폴더의 .codex/auth.json 에서 auth_mode 값만 봐줘. "chatgpt" 면 구독 모드(추가 과금 0), "apikey" 면 유료 과금 모드니까 알려줘. 토큰 값 자체는 절대 화면에 출력하지 마. 5) 도는지 한 번 시험해줘: codex exec --skip-git-repo-check --ephemeral -s read-only "한 문장으로 자기소개해줘" 답이 나오면 성공이야.

⚠️ 5번에서 노란 경고 로그가 여러 줄 지나갑니다 — 실패가 아닙니다. 다 지나간 맨 아래에 답 문장이 나오면 성공(강사 기기 실측 약 4초).

연결했으면 이렇게 씁니다 — 오늘 만든 요약·발표자료를 두 모델에게 동시에 검사시키는 것:

이 파일의 의학 내용이 맞는지 검토해줘. 그리고 codex exec로 GPT에게도 같은 파일을 주고 똑같이 검토시킨 다음, 너와 GPT의 판단이 엇갈리는 부분만 따로 표로 정리해줘. 엇갈리는 곳이 내가 교과서로 확인해야 할 곳이야.

🎯 일치하는 지적보다 엇갈리는 지적이 값집니다. 두 모델이 다르게 말한다 = 그 내용은 확실하지 않다는 신호예요. 시험 공부할 때 특히 유용합니다.

🅖 Gemini API 카드 등록 · 건당 과금

🛑 대부분은 필요 없습니다. 오늘 오후에 쓴 Gemini Notebook은 무료이고, 문헌·강의자료를 소화시키는 용도로는 그걸로 충분해요. API는 프로그램에서 자동으로 반복 호출할 때 쓰는 것이고, 카드를 걸고 호출할 때마다 요금이 붙습니다.

정말 필요해지는 날이 오면(예: 수백 건을 자동으로 돌려야 할 때) — aistudio.google.com/apikey에서 키를 받고, 키는 채팅창에 절대 붙여넣지 말고 .env.local 파일에 넣은 뒤 .gitignore에 등록하는 것이 표준입니다. Claude에게 "키는 내가 직접 파일에 써넣을 테니 빈 .env.local과 .gitignore만 만들어줘"라고 시키면 됩니다.
