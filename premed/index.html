Codex Local 또는 Claude Code Local에서 두 파일을 읽게 한 뒤, 한 문장을 보내면 AI가 현재 작업 폴더 안에 수업 환경을 준비합니다.

먼저 두 파일 다운로드

같은 위치에 저장해 앱의 로컬 작업 폴더로 엽니다.

작업 범위, 안전 경계, 수업 진행이 들어 있습니다.

prompt.md 다운로드

2. 수업 파이프라인

설치 도구와 수업 자료를 담은 단일 패키지입니다.

pipeline.zip 다운로드
Local 대화에 보낼 한 문장프롬프트대로 준비하고 시작해줘

학생이 할 일은 세 단계

1

데스크톱 앱 설치·로그인

ChatGPT 데스크톱 앱에서 Codex를 쓰거나 Claude 데스크톱 앱에서 Code를 엽니다. 사용할 수 있는 계정으로 로그인하세요.

2

두 파일이 있는 위치 열기

앱의 로컬 작업 공간에서 다운로드한 파일이 든 폴더를 엽니다. 새 빈 폴더, ZIP 해제, Python 설치는 필요하지 않습니다.

3

위 문장 한 번 보내기

일반 Chat 대화가 아니라 로컬 파일을 다루는 Codex 또는 Code Local 세션에서 보냅니다.

앱에서 Local 작업 공간 여는 방법
ChatGPT 데스크톱 → Codex

먼저 ChatGPT 앱 다운로드 ↗에서 설치하고 로그인합니다. 상단 메뉴에서 Codex를 선택해 두 파일이 있는 로컬 폴더를 연 뒤, OpenAI 공식 안내를 참고하세요.

Claude 데스크톱 → Code → Local

Claude 앱 다운로드 ↗에서 설치하고 로그인한 뒤, Code 탭에서 Local을 고르고 폴더를 선택합니다. 계정이 업그레이드를 요구하면 결제하지 말고 Codex 또는 강사 안내를 이용하세요. 자세한 내용은 Claude 공식 안내를 참고하세요.

강의와 보조 자료 보기
강의 HTML강의 PDF한 장 정리 PDFStudent Collab 구조 참고

실습은 수업 패키지의 합성 예시와 공개 자료를 기본으로 합니다. 본인 또는 사용 권한이 확인된 공저자 초안도 기관 보안 규정과 동의가 AI 처리를 허용할 때 사용할 수 있습니다. 환자 식별정보와 기관 기밀, 동의·권한이 확인되지 않은 파일은 입력하거나 외부 서비스로 보내지 마세요. Local 앱도 AI 서비스가 내용을 처리할 수 있습니다.

작업이 멈추면 AI가 확인한 단계와 오류만 강사에게 보여 주세요. 앱이 요청하는 필요한 권한만 검토하고, 업그레이드나 별도 API 구매는 하지 않습니다.
