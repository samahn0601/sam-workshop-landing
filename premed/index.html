AI가 맡는 설정

AI가 수업 자료를 내려받아 확인하고, 안전하게 압축을 풉니다. 문헌 실습은 수업 폴더와 실행 환경을 준비합니다. StatSam은 별도 통계 환경을 준비하고 실제 실행·검사 결과까지 확인합니다.

  • 다른 폴더나 개인 파일을 검색하지 않음
  • 관리자 권한, 시스템 PATH 변경, 추가 구독 구매를 요청하지 않음
  • 다운로드·명령이 앱 권한에 막히면 우회하지 않고 강사에게 알림

개인정보와 권한이 불분명한 원고는 넣지 마세요. 데스크톱 앱에서 로컬 폴더를 열어도 AI 서비스가 내용을 처리할 수 있습니다. 환자 식별정보, 비밀번호·API 키, 기관 기밀, 권한이 불분명한 공동저자 원고는 넣지 않습니다. 본인의 주제·초안이나 사용 권한과 비식별화를 확인한 CSV는 해당 트랙에서 사용할 수 있습니다.
