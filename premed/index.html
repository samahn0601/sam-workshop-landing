앱에 보낼 한 문장

prompt.md를 읽고 그대로 준비해서 시작해 줘.

일반 채팅이 아니라 Codex 또는 Claude Code의 Local 화면, 두 파일이 있는 폴더를 연 상태에서 보냅니다.

실습 중 붙일 문장 모음 →준비부터 연습 투고까지 단계별 문장을 복사 버튼과 함께 모았습니다. 내 아이디어로 할 때와 수업 뒤에 이어 할 때의 문장도 있습니다. 수업 내내 이 탭을 열어 두세요.

순서는 세 단계입니다

  1. 1데스크톱 앱 설치·로그인

    ChatGPT를 쓰면 ChatGPT 데스크톱 앱의 Codex, Claude를 쓰면 Claude 데스크톱 앱의 Code → Local을 씁니다. API 키나 별도 결제는 필요 없습니다.

    ChatGPT 데스크톱 앱 ↗Claude 데스크톱 앱 ↗

  2. 2다운로드 폴더 열기

    • Codex: 폴더 열기에서 두 파일이 있는 다운로드 폴더를 고릅니다.
    • Claude: Code 탭 → Local → Select folder에서 다운로드 폴더를 고릅니다.

  3. 3위 문장 보내기

    AI가 다운로드 폴더 안에 premed-workshop 폴더를 새로 만들고, 압축 해제와 Python 확인, 실행 점검까지 한 뒤 준비 완료(READY)를 알려 줍니다.

    • 앱이 명령 실행이나 폴더 접근 허용을 물으면 내용을 읽고 이 수업 폴더에 관한 것만 허용합니다. Full access나 권한 우회는 고르지 않습니다.
    • Python이 없다는 말이 나오면 AI가 먼저 준비를 시도합니다. 막히면 python.org에서 설치하고 같은 문장을 다시 보냅니다.
    • 결제나 업그레이드를 요구하면 결제하지 말고 강사에게 알려 주세요.

전에 student-collab.zip을 받았다면, 오늘은 그 대신 위의 두 파일을 씁니다.

수업 전에 확인할 것

  • 노트북과 충전기를 가져옵니다. 휴대전화나 태블릿만으로는 실습할 수 없습니다.
  • ChatGPT 또는 Claude 유료 구독 계정 1개 이상과 로그인 수단이 필요합니다. 두 개가 있으면 서로 다른 AI의 비평도 받아 봅니다.
  • 관심 있는 연구 주제 한 문장이 있으면 좋습니다. 없어도 괜찮습니다. 수업은 모두 같은 합성 사례로 처음부터 끝까지 진행합니다.

환자 식별정보, 비밀번호·API 키 같은 비밀값, 허가 없는 공동저자 원고, 기관 기밀은 넣지 마세요. 내 컴퓨터 폴더에서 작업하는 앱도 파일 내용을 AI 서비스에서 처리할 수 있습니다.
