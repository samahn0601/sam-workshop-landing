받는 순서는 세 단계입니다

  1. 1student-collab.zip 내려받기

    학생 안내(START_HERE.html), 실행기(pipeline.py), 단계별 요청문(prompts 폴더)이 모두 이 파일 하나에 들어 있습니다. 내려받은 파일은 보통 다운로드 폴더에 저장됩니다.

    student-collab.zip 내려받기

  2. 2압축 풀기

    • Windows: 다운로드 폴더에서 student-collab.zip을 오른쪽 클릭하고 모두 추출 → 추출을 누릅니다. 다운로드 폴더 안에 student-collab 폴더가 생깁니다.
    • macOS: 다운로드 폴더에서 student-collab.zip을 더블클릭합니다. Safari가 내려받으면서 이미 풀었다면 생긴 student-collab 폴더를 그대로 씁니다.
    • 반디집·7-Zip: ‘여기에 풀기’가 아니라 ‘student-collab\에 풀기’를 고릅니다. ‘여기에 풀기’는 파일을 다운로드 폴더에 흩어 놓습니다.

    Windows에서 ZIP을 더블클릭만 하면 압축 안을 들여다보는 창이 열릴 뿐, 파일이 풀린 것은 아닙니다. OneDrive 안의 깊은 폴더가 아니라 다운로드 폴더처럼 짧은 위치에 풀어야 Windows의 경로 길이 제한(260자)에 걸리지 않습니다. 이미 작업한 폴더가 있다면 지우거나 ZIP으로 덮어쓰지 마세요.

  3. 3START_HERE.html 열기

    풀린 student-collab 폴더에서 START_HERE.html을 더블클릭하면 브라우저에 학생 안내가 열립니다. 맨 위에 노란 경고가 없고 같은 폴더에 pipeline.py가 보이면 제대로 푼 것입니다.

    다운로드/
└─ student-collab/      ← 데스크톱 앱에 연결할 폴더
   ├─ START_HERE.html   ← 브라우저로 여는 학생 안내
   ├─ pipeline.py       ← 함께 보여야 합니다
   ├─ prompts/ · core/
   └─ incoming/         ← 드래프트 사본을 넣는 곳

    앱 설치와 로그인, 폴더 연결, 첫 요청, H1–H5에서 붙일 문장, 막혔을 때 할 일이 모두 START_HERE.html에 있습니다. 수업은 이 안내를 기준으로 진행합니다.

수업 전에 확인할 것

  • 노트북과 충전기를 가져옵니다. 태블릿이나 휴대전화만으로는 로컬 실행 실습을 하기 어렵습니다.
  • ChatGPT 또는 Claude 중 1개 이상의 유료 구독 계정과 로그인 수단이 필요합니다. 두 개가 있으면 서로 다른 제공자의 비평을 경험합니다. API 키나 별도 API 결제는 필요 없습니다.
  • 현재 요금제에서 로컬 폴더 작업을 쓸 수 있는지 확인합니다. 2026-10-11 공식 안내 기준으로 ChatGPT 데스크톱 앱의 로컬 작업은 Plus·Pro·Business·Edu·Enterprise 요금제 표에 있고, Free·Go는 일부 모델만 순차 제공으로 표시됩니다. Claude의 Code 탭은 Pro·Max·Team·Enterprise가 필요합니다.
  • Windows 또는 macOS 노트북을 씁니다. 기관 관리 기기는 설치 권한을 미리 확인합니다. Intel Mac이면 강사에게 미리 알려 주세요. 2026-10-11 공식 안내에서 ChatGPT 앱의 macOS 다운로드는 Apple Silicon용으로 표시되어 있었습니다. Windows ARM 노트북은 Claude 앱의 ARM64 설치 파일을 씁니다.
  • 관심 있는 논문 주제 한 문장, 또는 AI 서비스와 함께 써도 되는 권한이 확인된 드래프트 사본 한 문단을 준비합니다. 주제만 있어도 충분합니다.

미리 설치하려면 (필수 아님)

ChatGPT 데스크톱 앱 ↗Codex 로컬 폴더 작업 포함 Claude 데스크톱 앱 ↗Code 탭 시작 안내 Python 3.11 이상 ↗공식 설치 파일

Windows는 Python install manager를 설치한 뒤 터미널에서 python을 한 번 입력하면 최신 Python을 내려받습니다. 두 구독이 있어도 로컬 폴더에는 주 작업 앱 한 곳만 연결하고, 다른 서비스는 비평을 받을 새 대화로만 씁니다. 사전 설치는 참가 조건이 아니며, 설치와 로그인은 수업 시간에 함께 합니다.

환자 식별정보, 비밀번호·API 키 같은 비밀값, 허가 없는 공동저자 원고, 기관 기밀은 가져오지 마세요. 로컬 폴더를 쓰는 데스크톱 AI도 파일 내용을 외부 서비스에서 처리할 수 있습니다. 권한이 애매하면 주제를 추상화해 준비하고, 주제가 없으면 수업에서 주는 예시를 씁니다.
