# 이전 Claude 링크를 연 경우

이 파일은 호환용 안내입니다. 최신 준비 지시는 [prompt.md](prompt.md)에 있습니다.

1. 같은 폴더에 `prompt.md`와 `pipeline.zip`을 다운로드합니다.
2. Claude 데스크톱 앱에서 Code → Local을 열고, 두 파일이 있는 폴더를 선택합니다.
3. Code가 두 파일을 읽을 수 있는지 확인한 뒤 `프롬프트대로 준비하고 시작해줘`라고 보냅니다.

일반 Chat 대화에 파일만 첨부해도 컴퓨터의 로컬 폴더가 자동으로 준비되지는 않습니다. Claude Code가 계정 업그레이드를 요구하면 결제하지 말고 Codex Local 또는 강사 안내를 이용하세요.
