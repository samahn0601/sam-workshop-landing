0운전석 정하기 · 병용 트랙만 있는 절

두 앱을 동시에 몰지 않습니다. 파이프라인을 끝까지 도는 앱은 하나이고, 다른 앱은 문헌 엔진과 심사자로만 부릅니다.

둘 다 구독하고 계신 분이 오늘 얻는 것은 세 가지입니다.
첫째, 문헌 딥리서치를 두 회사 엔진으로 돌립니다. 두 엔진이 서로 놓친 문헌을 메우기 때문에 합집합이 한쪽보다 넓습니다.
둘째, ⑥ 심사자 비평에 다른 회사 모델을 네 번째 독립 심사자로 붙입니다. 학습 데이터가 다른 모델이라서, 두 모델의 판단이 엇갈리는 자리가 드러납니다.
셋째, 운전석이 아닌 앱의 고급 기능을 브라우저 창으로 끌어다 씁니다. ChatGPT Pro 구독자의 Pro 추론 프리셋이나 claude.ai의 연구 기능처럼, CLI에는 없고 앱에만 있는 기능이 그렇습니다.

규칙 세 줄

① 두 구독 중 티어가 높은 쪽 앱을 운전석으로 삼습니다. 한도가 더 넉넉한 쪽으로 파이프라인 전체를 돌리는 것이 안전합니다.

② 티어가 같으면 Claude 데스크탑 앱의 Code 탭을 권합니다. 이유는 두 가지입니다. ⑥ 비평에서 리뷰어 셋을 서브에이전트로 동시에 띄울 수 있고, ChatGPT 쪽 고급 기능(Pro 프리셋과 딥리서치)은 어차피 브라우저 창으로 쓰기 때문입니다.

③ 이미 매일 쓰는 앱이 있으면 그 앱을 운전석으로 하셔도 됩니다. 손에 익은 쪽이 실습 속도에서 유리합니다.

⭐ 운전석을 정하면 이 페이지에서 읽을 곳이 줄어듭니다.
§1 · §2 · §4 · §5는 운전석 트랙 페이지(gpt.html 또는 claude.html)의 같은 번호 절을 따르세요. 이 페이지는 그 위에 두 번째 앱을 붙이는 방법만 다룹니다. 절 번호는 세 트랙이 같으니, 강사가 "지금 ○절입니다"라고 부르면 같은 자리에 계시게 됩니다.

4입력창 한 바퀴 · 운전석 기준으로

입력창 구조는 운전석 앱마다 다릅니다. 운전석 트랙 페이지 §4를 그대로 보세요. gpt.html §4 또는 claude.html §4.

두 번째 앱은 입력창으로 만나지 않습니다. CLI로 부르거나, 운전석 앱의 브라우저 창으로 사이트를 열어 만납니다.
다행히 두 앱의 내장 브라우저 열기 단축키가 같습니다. 둘 다 Windows에서 Ctrl+Shift+B, macOS에서 Cmd+Shift+B입니다. 그래서 운전석을 어느 쪽으로 정하셔도 손가락 기억은 하나면 됩니다.
Claude 쪽은 이 키가 토글이라 한 번 더 누르면 닫히고, 포커스된 패널만 닫을 때는 Ctrl+\입니다. macOS는 Cmd+\입니다.

6문헌 찾기 · 두 회사 딥리서치를 합칩니다

운전석 딥리서치는 운전석 트랙 페이지 §6대로 한 번 돌립니다. 여기서는 두 번째 회사 딥리서치를 같은 자리에서 한 번 더 돌리는 방법을 다룹니다.

다른 회사 사이트는 운전석 앱의 내장 브라우저에서 엽니다. 운전석이 Codex이면 그 브라우저에서 claude.ai의 연구 기능을, 운전석이 Claude이면 Browser pane에서 chatgpt.com의 딥리서치를 씁니다.
근거는 두 가지입니다. 두 내장 브라우저 모두 외부 사이트 로그인이 됩니다. 그리고 둘 다 개인 브라우저와 분리된 프로필이라서, 평소 로그인이 따라오지 않고 그 창에서 따로 로그인해야 합니다.
🔑 로그인은 사람이 합니다. 비밀번호는 AI가 대신 입력하지 않습니다. 로그인이 안 돼 있으면 거기서 멈추고 여러분을 부르는 것이 정상 동작입니다.

🅐 운전석이 Codex일 때 · 내장 브라우저에서 claude.ai 연구 기능

두 번째 문헌 엔진으로 Claude의 연구 기능을 쓰고 싶어. 아래 순서대로 네가 직접 해줘. 1) 내장 브라우저를 열고 claude.ai 로 이동해줘. 2) 로그인이 안 돼 있으면 거기서 멈추고 나에게 알려줘. 비밀번호는 절대 대신 입력하지 마. 내가 로그인을 끝낼 때까지 기다려줘. 3) 새 대화를 열고 연구(Research) 기능을 켜줘. 4) 아래 연구질문을 그대로 입력해줘. [여기에 내 연구질문을 넣는다] 5) 입력이 끝나면 전송 버튼을 눌러. Enter 키는 줄바꿈이 될 수 있어. 그다음 결과가 끝날 때까지 기다려줘. 몇 분 걸리니까 중간에 멈추지 마. 6) 화면에 나온 결과를 그대로 02_research/deep_research_claude.md 에 저장해줘. 요약하지 말고, 없는 내용을 보충하지도 말고, 화면에 있는 것만 옮겨. 인용은 원문 표기 그대로 남겨.

Claude의 연구 기능은 유료 플랜에서 열립니다. 무료 계정으로 로그인하면 메뉴가 안 보입니다.

게이트왜

ChatGPT 개인 계정 — 앱 설정 → 계정(↗) → 웹 설정 → 데이터 제어 → 「모델 개선을 위한 데이터 학습 허용」 꺼짐.

🔒 인용 실재 확인날조 인용은 데스크 리젝트를 넘어 연구 진실성 문제가 됩니다.
🔒 제출은 사람이포털 로그인·제출 버튼은 저자 본인의 행위입니다. AI가 누르지 않습니다.
🔒 의학적 판단 확인약물 용량·IRB·가이드라인 서술은 저자가 책임집니다.

13막히면 · 병용 트랙에서 자주 나오는 것

증상이렇게 하세요
"API 키가 필요합니다"라고 한다 §8의 되받기 프롬프트를 붙여넣으세요. 양쪽 방향 모두 있습니다. GPT를 붙일 때는 codex login, Claude를 붙일 때는 claude auth login이 구독 로그인 경로입니다. 자주 있는 오답이니 당황하지 않으셔도 됩니다.
codex login 또는 claude auth login이 한참 반응이 없다 실패가 아닙니다. 브라우저에서 여러분이 로그인을 끝낼 때까지 기다리는 중입니다. 브라우저 창을 찾아 로그인을 마치면 이어집니다.
내장 브라우저에서 다른 회사 사이트가 로그아웃 상태다 정상입니다. 두 앱의 내장 브라우저는 개인 브라우저와 분리된 프로필을 쓰므로 평소 로그인이 따라오지 않습니다. 그 창에서 따로 한 번 로그인하시면 됩니다. 비밀번호는 AI가 대신 넣지 않습니다.
쿼터에 걸렸다고 한다 잠시 쉬었다 다시 됩니다. 구독 쿼터를 쓰는 경로라서 그렇습니다. Claude는 채팅과 Code가 한도를 공유하니 비평을 두 번 돌린 직후에 자주 만납니다. 사용량은 설정의 Usage에서 확인하세요.
그 밖의 증상 운전석 트랙 페이지 §13을 보세요. gpt.html §13 또는 claude.html §13. 앱 자체 문제는 대부분 그쪽에 정리돼 있습니다.

14AI가 "안 됩니다"라고 할 때

🪄 AI가 "안 됩니다"라고 할 때 — 이걸 붙여넣으세요

가장 자주 겪는 실패는 기능이 없어서가 아니라 AI가 지레 "불가능하다"고 답해서입니다. 아래는 그 판단을 강제로 점검시키는 규칙입니다.

## 실현가능성 판단 규칙 불가 판정 전에 다음을 구분하라. 1. 기술적으로 불가능 2. 공식 지원은 아니지만 가능 — 쓸 경우 비공식 경로임을 반드시 밝힌다 3. 현재 방법만 실패 4. 정보나 권한이 부족함 5. 정책상 하지 않음 — 1번과 섞지 말 것. 우회로를 찾지 말 것. "불가능"이라고 답하려면 공식 문서 · 실제 오류 메시지 · 환경 제약 중 최소 하나의 명확한 근거를 제시해야 한다. 그전에는: - 현재 환경과 설치된 도구를 직접 확인한다 - 공식 경로를 우선 탐색한다 - 첫 실패 후 최소 2개의 대안을 시도한다 - 오류 메시지를 근거로 계획을 수정한다 - 대안이 소진되거나 도구 호출 20회를 넘기면 멈추고 현황을 보고한다 설명만 하지 말고 실제로 수행하라. 성공 보고도 같은 기준이다 — 실행 출력이나 테스트 결과 없이 "됐습니다" 금지. 막히면 "안 된다"가 아니라 어디까지 성공했고 무엇이 막혔는지 보고하라. 예외 — 되돌릴 수 없는 작업은 이 규칙 밖이다. 삭제, 원고 덮어쓰기, 결제, 외부 전송, 저널 제출, 인증정보 입력, force push, DB 마이그레이션은 시도 전에 먼저 확인받는다.
📌 매번 붙여넣기 번거로우시면 — 파일에 넣어두시면 됩니다.
작업 폴더에 파일을 만들고 위 내용을 넣으면, 그 폴더에서는 항상 적용됩니다. 만드는 것도 시킬 수 있습니다 — "이 폴더에 파일 만들고 방금 규칙 넣어줘". Codex는 AGENTS.md, Claude Code는 CLAUDE.md가 같은 역할을 합니다.
⭐ 왜 이게 오늘의 핵심에 닿는가 — 이 규칙의 마지막 두 줄이 진짜입니다.
"실행 출력 없이 '됐습니다' 금지" · "어디까지 성공했고 무엇이 막혔는지 보고하라"
AI가 안 된다고 할 때도, 됐다고 할 때도 근거를 요구하는 것 — 그게 오늘 배우실 판단의 전부입니다. 되돌릴 수 없는 일(삭제·제출·결제)에는 이 규칙을 적용하지 않는다는 예외도 같은 이유입니다.
