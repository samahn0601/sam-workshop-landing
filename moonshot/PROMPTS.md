# 내 주제로 바꾸는 여덟 요청 문장

1) 질문: 나는 [전공] 학부생이야. 내 질문: [질문]. 내 예상: [한 줄]. 대상, 개입, 비교, 결과로 나누고, 다른 설명 세 가지와 이 질문으로 말할 수 없는 것 세 가지를 적어 줘. 문헌이나 숫자는 지어내지 마.
2) 독자: 아래는 [학술지나 학회]의 공식 안내문에서 내가 복사한 범위 설명이야. 편집자라면 내 개요를 돌려보낼 이유 세 가지를 적어 줘. 안내문에 없는 규정은 지어내지 마.
3) 근거: 내 주장과 관련된 문헌 후보를 표로 정리해 줘. 반대 결과를 보고한 문헌도 찾고, 못 찾았으면 ‘못 찾음’이라고 써 줘. 원문을 열지 못했으면 ‘확인 불가’로 쓰고 판정 칸은 비워 둬.
4) 계획: 아직 계산하지 마. 먼저 분석 계획만 써 줘. 가장 중요하게 볼 결과는 [하나]야. 내가 승인하면 그때 실행해.
5) 계산: 승인한 계획대로 코드로 계산하고, 코드와 입력 파일과 결과 파일을 함께 보여 줘. 실행하지 못했으면 숫자를 쓰지 마.
6) 초안: 확인한 재료만 써서 초안을 만들고, 내가 확인해 줘야 하는 정보는 [저자 확인 필요]로 비워 둬. 다듬은 뒤에는 바뀐 숫자와 인용을 목록으로 보여 줘.
7) 비평: 너는 이 원고를 처음 보는 까다로운 심사자야. 칭찬은 빼고 번호를 붙여 지적하고, 해당 문장을 그대로 인용해 줘.
8) 60초 점검: 내가 설명하지 못할 것 같은 질문 세 개만 내 줘. 답은 알려 주지 마.

## 매 단계 마지막에 붙일 문장

지금 있는 자료, 다음에 내가 할 결정 하나, 확인할 근거, 그대로 복사할 다음 요청 문장을 알려 줘. 하지 않은 일을 완료했다고 쓰지 마.
