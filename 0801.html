시작하자
⭐ 교수 필수 3가지 — ① 가짜 인용/DOI: AI는 없는 논문을 지어냅니다. 파이프라인의 참고문헌 점검(PubMed·Crossref 실검증)을 반드시 통과 + 최종은 본인 확인. ② AI 저자성/공개: 요즘 저널은 AI 사용 공개문을 요구합니다. ③ Human Final Gate: 자동 점검 통과(Green) ≠ 제출 가능 — 실제 투고 직전 본인이 최종 관문.
⑧투고 이후는 어디까지 되나요? — 파이프라인은 10단계 전부를 다룹니다. ⑨ 리뷰 대응은 전용 도구가 들어 있어(리비전 결정을 받으면 편집장 서신·리뷰어 코멘트를 넣고 point-by-point 응답서 + 개정 원고를 만듭니다) 투고 뒤 실제로 쓰는 단계입니다. 투고 상태 추적·마감 관리는 오늘 오후 데모①에서 보여드리는 그 방식(메일·캘린더 연결)이 그대로 실무 도구입니다.
🔒 다만 세 가지는 설계상 사람 몫으로 잠겨 있습니다 — 포털 자격증명·로그인, Submit 버튼, 그리고 실제 심사 원문의 최종 판단. 자동화하지 않는 것이 아니라 자동화하면 안 되는 지점입니다(비가역·외부 노출·저자 책임). 게재 여부는 도구가 약속할 수 있는 것이 아닙니다 — 오늘 산출물은 "투고를 겨냥한 원고"이지 "투고해도 되는 원고"가 아닙니다(submission-directed ≠ submission-ready). 그 사이에 참고문헌 전수 실존 확인 · AI 사용 공개문 · 데이터 적법성이 남습니다.
오늘 하루의 도달 범위는 앞 단계 2~4개이고, 나머지는 같은 폴더에서 그대로 이어집니다 — 프롬프트·스킬 전부 재사용.

＋Claude 단독이 기본 · GPT는 선택 · 개인 ChatGPT 구독자만 · 없어도 무방

오늘 파이프라인은 Claude Team 시트만으로 끝까지 됩니다 — 추가 도구·API 키 불요. 아래는 개인 ChatGPT(Plus/Pro) 구독이 있는 분을 위한 선택 옵션이며(논문 도구 스킬에도 선택 단계로 반영돼 있음), 없어도 워크숍 진행엔 전혀 지장이 없습니다.
단계GPT를 이렇게 곁들일 수 있어요 (선택)
② 문헌 검색ChatGPT 심층 리서치(Deep Research)를 Claude Research와 병행 — 엔진이 서로 놓친 문헌을 메워 커버리지↑. 결과를 같은 파일에 합치고, 인용은 ⑤에서 실재 확인.
⑥ CriticClaude 다관점 비평에 GPT를 "제2 심사자"로 추가 — 의견이 엇갈릴수록 값집니다(단일 모델 맹점 상쇄).
보조ChatGPT 에이전트·브라우징으로 저널 투고규정·보고지침 페이지 확인 보조. 단 포털 로그인·제출은 🔒 본인이 직접.
연결 방법 2가지 · 간단 = 비평·질문을 브라우저 ChatGPT에 붙여넣기(설정 없음) · 무과금 연결(OAuth) = Codex OAuth로 Code 탭 안에서 Claude가 GPT를 직접 호출(별도 OPENAI_API_KEY 과금 없이 ChatGPT 구독 쿼터 사용). 연결 설정은 집에서 아래 복붙:
ChatGPT 구독으로 GPT를 무과금 연결(OpenAI Codex CLI, OAuth 로그인)하고 싶어. 내 OS에 맞게 Codex를 설치하고 codex login으로 ChatGPT 계정 로그인하는 것까지 안내해줘. 시스템을 바꾸는 명령은 실행 전에 꼭 확인받아.

※ 공식 "무과금 API"가 아니라 구독(ChatGPT Plus/Pro) OAuth 쿼터를 쓰는 비공식 경로 — 쿼터 제한이 걸리면 유료 API 키 폴백이 필요할 수 있습니다. Claude 단독도 완전한 경로이니 부담 없이 선택하세요.

🔵 3부 · 고급 활용 진행 중 남는 시간에 수시로 — 관심 가는 것부터

+고급 활용 메뉴 · 오늘 일부를 시연·맛보기, 나머지는 take-home

순서 강제 없음 — 강사가 진행 흐름에 맞춰 골라 시연하고, 각자 관심 있는 것부터 따라 해도 됩니다. 설정 단계 상세는 🅱 자동화·비서 퀵스타트에 전부 있습니다. (퀵스타트는 7/9 자료 — 무료 프로모션 등 시점 정보는 달라졌을 수 있음)

① 투고 메일 추적 + 마감 캘린더 · 교수 체감 1위

설정 ▸ Connectors에서 Gmail·구글 캘린더 연결(Team 플랜 동작·조직 사전 활성화 필요) → 투고 상태를 표로, 마감을 캘린더로.

내 Gmail에서 최근 30일간 저널 편집장/투고시스템 메일(editorialmanager·scholarone·manuscriptcentral 도메인, 또는 'decision/revision/manuscript ID/under review' 포함)을 찾아, 논문별 상태를 표로 요약해줘. 리비전 마감 등 기한이 보이면 구글 캘린더에 일정으로 넣어줘(넣기 전 확인). 회신이 필요한 건 자동 발송하지 말고 초안만 만들어줘.

※ 커넥터는 "물어볼 때만" 동작 — 상시 자동 점검은 ④ 헤르메스 같은 에이전트의 예약(cron) 몫. 연결이 막히면(조직/학교 정책) 데모 화면으로 대체합니다.

② LLM wiki — 인물 노트 실습 + 읽은 논문 쌓기

에이전트가 Markdown 노트를 쌓고 연결해 쌓을수록 똑똑해지는 지식베이스(Karpathy LLM wiki 패턴). 오늘은 두 용도로 — ㉮ 인물 노트 실습(감 잡기 가장 쉬움)과 ㉯ 읽은 논문 서재.

㉮ 인물 노트 실습 — 가상 인물 2~3명을 넣고 "이번 달 생일인 사람?" 같은 질문으로 여러 노트를 가로질러 답하는 걸 체험:

이 폴더에 '인물 노트 wiki'를 시작하자. people 폴더를 만들고, 내가 사람 정보를 주면 한 명당 노트 한 개(이름·생일·자녀 이름/나이·근황·마지막 만남)로 정리해줘. 전체를 한눈에 보는 index.md도 만들어 계속 갱신하고. 먼저 구조와 빈 템플릿부터. (실습은 가상 인물로)

㉯ 읽은 논문 서재 — 같은 원리로 논문 노트를 쌓으면 "작년에 읽은 것 중 ○○ 다룬 논문?"에 즉답:

이 폴더에 '읽은 논문 wiki'를 시작하자. papers 폴더에 논문별 노트(서지정보·핵심 결과·내 코멘트·관련 논문 링크)와 전체 index.md를 만들고 계속 갱신해줘. 먼저 구조와 빈 템플릿부터.

제대로/오래 쓰려면 Karpathy 공개 gist를 붙여넣고 "이대로 만들어줘" → index+log·교차링크까지 일관. 옵시디언으로 열면 그래프로 보임 · 실제 인물 정보는 내 기기에서, 본인 판단으로.

③ K-skills — 한국형 스킬 이식

법령·식약처·HWP·맞춤법·지도·예약 등 한국형 스킬 모음(github.com/NomaDamas/k-skill). 터미널 명령 없이 Code에 시키면 설치까지.

NomaDamas의 k-skill 중 맞춤법 검사(korean-spell-check) 스킬을 설치해줘. github.com/NomaDamas/k-skill 공식 방법을 확인해서 진행하고, 되면 아무 문서로 한 번 시험해줘.

④ 헤르메스 — 자율 비서 에이전트 · 개요·데모

Nous Research의 오픈소스 자율 에이전트 — PC에 상주하며 영속 기억 + 예약(cron) 실행으로 ①의 투고 추적을 "매일 아침 자동 점검"으로 상시화. 텔레그램·슬랙에 붙이면 폰에서 비서와 대화.

브레인(모델)·메시징 설정은 외부 계정 발급이 필요해 집에서 천천히 — 단계 전부 🅱 퀵스타트 5번 절에.

notebooklm.google → 개인 구글 계정 로그인(학교 Workspace는 막힌 경우 있음) → 새 노트북 → PDF 업로드 → 출력 언어 한국어. ⭐ 답변의 출처 인용을 클릭해 원문 근거로 점프해 보세요 — "AI가 지어낸 게 아니라 내 소스에서 왔다"를 눈으로(가짜 인용 경계 습관과 직결). ⚠️ 무료 한도: 오디오 ~3/일·비디오는 더 제한적.
