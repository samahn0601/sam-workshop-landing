1알림장·가정통신문 정리 웹 · claude.ai

가정통신문 사진을 📎로 첨부한 뒤 붙여넣기. (실명·학교 가린 샘플로)

한 장 정리 (가장 쉬움)

첨부한 가정통신문에서 이번 주 준비물·제출물·날짜만 표로 정리해줘. 아이 이름과 학교명은 빼고.

→ 흩어진 통신문이 주간 체크리스트 한 장으로.

여러 장 합치기 (심화)

첨부한 통신문들을 합쳐서 주간 체크리스트로 만들어줘. 마감일 순으로 정렬하고, 캘린더에 옮길 수 있게 [날짜 | 항목 | 준비물]만 깔끔하게.

2학습 코치 웹 · claude.ai + Gemini Notebook

빠른 코칭은 claude.ai, 교재 기반 학습자료는 Gemini Notebook(학습 특화).

개념을 아이 눈높이로 (claude.ai)

초등 4학년이 이해하게 '분수의 덧셈'을 아이가 좋아하는 것(예: 피자)에 비유해 설명하고, 끝에 이해 확인 질문 2개 내줘.

문제 + "정답 말고 힌트" (claude.ai)

초4 분수 덧셈 연습문제 5개와 풀이를 만들어줘. 난이도를 조금씩 올리고, 아이가 틀리면 정답 말고 힌트부터 주는 식으로.

Gemini Notebook 학습자료 (교재/필기 업로드 후)

버튼으로 학습가이드·플래시카드·퀴즈 자동 생성, Audio/Video Overview로 5분 요약 강의. 프롬프트로 다듬을 때:

이 자료로 초등학생용 플래시카드 20장과 퀴즈 10문제를 쉬운 말로 만들어줘.

🆕 Gemini 'Study Notebooks'가 보이면: 교재 올리고 진단 퀴즈부터 → 약점 맞춤 학습. (안 보이면 위 Gemini Notebook으로 — 같은 효과)

→ Gemini Notebook은 올린 자료 안에서만 답해 엉뚱한 소리(환각)가 적어요.

3글쓰기 코칭봇 + 표현 다듬기 웹 · claude.ai

답 안 주는 글쓰기 코치 (아이 글을 가명으로 붙여넣기)

너는 초등 글쓰기 코치야. 아이 글을 대신 고쳐주지 마. 칭찬 1개와, 더 생각하게 하는 질문 3개만 해. 절대 완성된 문장을 써주지 마.

매일 쓰려면 claude.ai Projects에 저장 = "우리 집 글쓰기 코치".

표현 다듬기 / 같은 말을 다르게

이 문장을 초등학생이 쓸 법한 더 생생한 표현 3가지로 바꿔 보기로 보여줘. 고르는 건 아이가 하게.
⚠️ 숙제 대필·AI 글 위장용이 아닙니다. 표현을 배워 아이가 직접 자기 말로 다시 쓰는 학습 도구예요.

4여행·체험학습팩 웹 · Gemini Notebook (②에서 배운 도구)

여행지 자료(위키 링크·박물관 PDF·메모)를 업로드 후 — 차에서 들을 오디오, 현장에서 풀 퀴즈.

아이용 여행 학습가이드 + 퀴즈

이 자료로 아이용 여행 학습가이드와 퀴즈 10개, 그리고 가볼 곳 타임라인을 초등학생 눈높이로 만들어줘.

→ Audio/Video Overview(버튼)로 차에서 들을 여행 개요까지.

5아이 영상 편집 Code · Claude Code + ffmpeg (내 컴퓨터·로컬)

영상 폴더를 Code 탭으로 열고 한국어로 시킵니다. 영상은 내 컴퓨터에서만 처리돼 밖으로 안 나갑니다.

(필요할 때) ffmpeg 설치

ffmpeg를 설치해줘 — 내 OS(Windows)에 맞는 공식 방법으로. 시스템을 바꾸는 명령은 실행 전 나한테 확인받아.

자르기 (가장 쉬움)

이 영상 앞 5초만 잘라줘. 원본은 그대로 두고 새 파일로 저장해줘.

이어붙이기 + 자막

이 3개 클립을 하나로 이어붙이고, 끝에 '우리 가족 여행 2026' 자막을 3초 넣어줘.

하이라이트 + 음악 (심화)

이 영상을 하이라이트 30초로 줄이고, 자막이랑 배경음악(bgm.mp3)을 넣어줘.

→ ⭐ 끝나면 파일 탐색기에서 완성된 .mp4를 더블클릭 재생. (채팅으론 못 하는 일)

🎁보너스 — 코딩 없이 웹앱 만들기 웹 · claude.ai Artifacts

우주 테마의 '칭찬 스티커판' 웹앱을 만들어줘. 칸을 클릭하면 별이 하나씩 채워지게.

→ 오른쪽에 바로 작동하는 앱. 응용: 용돈 기입장, 구구단 게임, 방학 생활계획표.

🏫보너스 — 우리 아이 학교 통째로 Code · NEIS 공개 API · 무료·무key

"Code는 영상만이 아니에요" — 학교명만 바꾸면 우리 아이 학교 데이터를 실시간으로. 공개 데이터라 개인정보 걱정 없음. (라이브 검증됨)

급식 (알레르기까지)

천안아름초등학교 이번 주 급식표를 만들어줘. NEIS 급식 공개 API(open.neis.go.kr)로 학교코드를 찾고, 알레르기 번호는 이름으로 풀어주고, 우유·계란 들어간 메뉴는 따로 표시해줘.

→ 실시간 급식표 + 알레르기. 응용: "우유 알레르기 날 저녁은 칼슘 보충 메뉴 추천."

학사일정 · 시간표 · 동네 학원 (학교명만 바꾸면)

천안아름초 이번 학기 학사일정(시험·행사·휴업일)을 캘린더로 정리해줘. (NEIS 학사일정 API)
천안아름초 3학년 이번 주 시간표 알려줘. (NEIS 초등 시간표 API)
천안 지역 초등 영어·수학 학원/교습소를 분야별로 뽑아줘. (NEIS 학원정보 API)

💡 키를 받으면(가정용): 미세먼지·날씨·공휴일·도서관도 같은 식으로.
